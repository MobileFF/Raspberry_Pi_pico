## 概要

9600bpsのUART通信内容をファイルとしてSDカードに保存したり、SDカードに入っているファイルの内容をUARTに出力したりすることができる自作電子工作「UART WR Box」のファームウェアになります。

Raspberry Pi picoのMicroPythonで動作させる前提のプログラムコードとなっています。

UART WR Boxは主に以下のモジュールを利用しています。

- OLEDディスプレイ：SSD1306
- SDカードスロットモジュール（型番不明：Amazonで入手）
- UARTレベルコンバータ：ADM3202
- タクトスイッチ４個

そのため、Rapsberry Pi pico標準の`ssd1306.py`と`sdcard.py`が別途必要です。

## 保存時の仕様について

もともと、カシオのPB-1000というポケットコンピュータのBASICプログラムを簡単に保存管理するために作った工作のため、SDカード保存時のファイル名については以下の仕様となっています。

- 先頭行に「'」（シングルクオーテーション：多くのBASIC言語ではコメントを示す記号）があったら、その後ろにある名称をファイル名とみなして保存する。
- 上記が該当しない場合は、"FOOBAR.TXT"という名称で保存する

たとえば、保存するBASICプログラムの先頭行が以下のようになっていたら

```basic
1 'MOBILEFF.BAS
```

SDカードには、`MOBILEFF.BAS`という名前で保存されます。

ちなみに読み込み時(LOADモード)のデータの取扱いはデータ受信側に依存しますので、特別な処置はしていません。

## 利用シーン：PB-1000でUART WR BoxへBASICプログラムを保存、読み込みするには

PB-1000にSDカードに入れたBASICプログラムを保存、読み込みする場合は、まず前提としてFA-7/MD-100などのRS-232Cインターフェースを持つオプションが必要になります。本体のみではそのままではUART通信はできませんのでご了承ください。

### SDカードからのBASICプログラム読み込み

SDカードには、以下の仕様でプログラムを保存しておいてください。

- テキストファイルとして保存
- エンコーディングはSJIS
- 改行はCR+LF
- 半角カナは利用可能

1. PB-1000のメニューで[load]→[RS232C]→[`load"COM0:7,N,8,1,N,N,N,B,N]と進んで[EXE]を押下します。
2. UART WR Boxで`LOAD`を表示→`決定`ボタン押下。対象のファイルを左右ボタンで選択したら`決定`ボタンを押すと`PRESS [OK]`と表示されるので再度`決定`ボタン押下します。
3. SDカードのファイル内容がUART経由でPB-1000に送信されます。
4. PB-1000側では無名のメモファイル(ファイルタイプS)ができていますので、メニューの[name]で適当なファイル名をつけます。
5. メニューの[basic]でBASICモードに移行します。
6. さきほど名前をつけたファイルを、`LOAD"ファイル名`で読み込みます。
7. メニューに戻ると、無名のBASICファイル（ファイルタイプB）ができていますので、メニューの[name]で適当なファイル名をつけます。
8. 先にできていたメモファイルは不要になるので[kill]で削除してもかまいません。

### SDカードへのBASICプログラムの保存

1. UART WR Boxで`SAVE`を表示→`決定`ボタン押下。`PRESS [OK]`と表示されるので再度`決定`ボタン押下すると`save start...`と表示され受信待機状態に入ります。
2. PB-1000のメニューで保存したいファイルに対して[save]→[RS232C]→[`load"COM0:7,N,8,1,N,N,N,B,N]と進んで[EXE]を押下します。
3. PB-1000のBASICプログラムがUART経由でUART WR BoxのSDカードに保存されます。
4. このとき、PB-1000側はEOFを送信しないため、UART WR Boxの受信が完了しません。後述する`EOF.BAS`などを使ってEOFを出力すると、UART WR Box側で`Finish.`と表示され保存が完了します。

#### PB-1000でUARTのEOF(&H1A)を出力するには

PB-1000のメニュー機能のUART出力は、最後にEOFを出力しない仕様になっているため、そのままでは受信側で通信終了を検出できません。そのため、PB-1000側に以下のようなBASICプログラムを用意しておき、[save]終了後にこのプログラムを実行します。

```basic
1 'EOF.BAS
1000 OPEN"COM0:7,N,8,1,N,N,N,N,N" FOR OUTPUT AS #1
1010 PRINT#1,CHR$(&H1A)
1020 CLOSE #1
```
